# Project plan

| Phase | Acceptance |
| --- | --- |
| 1. Foundation | PostgreSQL migration upgrades and downgrades. Seed is reproducible and rerunnable. |
| 2. Operations | Equipment, inventory and quality APIs enforce data and workflow invariants. |
| 3. Reliability workflows | Work orders, calibration, non-conformances and corrective actions retain history. |
| 4. Analytics | Sorter importer validates and deduplicates; native SQL answers operational questions. |
| 5. Interface | Responsive dashboard, workflows and CSV exports work against PostgreSQL. |
| 6. Verification | Pytest, Playwright, security review and measured query plans. |
| 7. Handoff | Reproducible startup, diagrams, screenshots, deployment and interview guides. |
| 8. Integration | Private GitHub repository, portfolio integration where source is available, LinkedIn drafts. Public changes require approval. |
